# Bill of Rights resource library

Acquired and verified September 8, 2026. Original publisher PDF bytes are preserved.

152 newly downloaded files, 6,529 pages. The existing three Fourth Amendment PDFs are retained separately by the page generator.

New files per amendment: 1: 15, 2: 15, 3: 15, 4: 15, 5: 15, 6: 16, 7: 16, 8: 15, 9: 15, 10: 15.

The manifest records source URLs, local paths, dates where established, page counts, byte counts, and SHA-256 checksums. Contextual and dated sources are labeled on the pages. This is a curated research collection, not a comprehensive statement of current law.

## Maintenance

- Source catalogue: `data/bill-of-rights-resources.json`. The four range manifests retain acquisition records.
- Rebuild static page listings: `python scripts/build-bill-of-rights-library.py`.
- Validate files and amendment mapping: `python scripts/verify-bill-of-rights-library.py --check-pages`.
- With the server running, also verify actual served bytes: add `--base-url http://localhost:8080`.
- PDF parsing and page generation use Python `pypdf`.
