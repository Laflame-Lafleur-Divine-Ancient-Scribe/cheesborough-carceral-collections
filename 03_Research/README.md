# Research Workspace

Use numbered folders for graduate research workflow:

1. `01_Literature-Notes` for reading notes and summaries.
2. `02_Case-Law` for opinions, briefs, statutes, and legal analysis.
3. `03_Archival-Notes` for collection notes, interviews, timelines, and source observations.
4. `04_Citations` for citation exports and bibliography files.
5. `05_Drafts` for working chapters, exhibits, and writing.
6. `99_To-Review` for materials that still need sorting.
